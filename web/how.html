How it works

A video goes in. Three sets of signals are pulled out of every second, compared with research and with typical videos in its genre, and turned into timestamped fixes whose evidence is checked against the video.

3 AI callsper video: transcript, screen description, fixes. Everything else is plain code.
7–15¢per video with fixes, measured on 30 s to 10 min videos.
1–2 minper video with fixes, mostly waiting on the models.

The pipeline

Plain code, free and repeatableAI model call
Video file or YouTube link

Up to 15 minutes are analysed.

↓
1Ingestplain code

Downloads at 480p (yt-dlp), cuts the window and extracts the audio (ffmpeg).

↓
2Visualplain code

Shot cuts and one frame per shot (PySceneDetect); motion, brightness and colour (OpenCV).

3Audio and speechWhisper

Word-timed transcript, plus loudness, silence and tempo (librosa) for words per minute and pauses.

4VisionGemini Flash

Watches at 1 frame per second: type of footage, faces, exact on-screen text, a description of each scene, the hook.

↓
5Fingerprintplain code

About 20 numbers per video (cuts per minute, time to first word, on-screen text share…) plus a second-by-second timeline.

↓
6Compareplain code

Against 16 researched parameters, each with its source, and the range of 35 real videos in 6 genres. 25 detectors mark problem moments: slow hook, static stretch, dead air.

↓
7FixesClaude Sonnet

Reads the measurements and problem moments and writes timestamped fixes. Every fix must cite its evidence.

↓
8Check the evidenceplain code

Re-checks every cited number, quote and timestamp against the measured data. Anything that doesn't match is flagged, not shown as verified.

↓
Report

Timeline, pain points, fixes with verified evidence, frames, and a second-by-second log of what's on screen and what's said.

Where it runs

Website

GitHub Pages. The demos are pre-computed files, so they need no server.

API

Google Cloud Run, one small container that scales to zero.

AI models

Whisper, Gemini and Claude through one gateway (LLM Foundry).

Usage limits

A daily budget in Cloud Storage; each run reserves its worst-case cost before starting.
